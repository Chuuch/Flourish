# UI Design Rules

Build interfaces that feel intentionally designed, not AI-generated.

## Avoid

- Gradient backgrounds
- Glassmorphism
- Excessive rounded cards
- Every section being inside a card
- Huge hero headings
- Excessive use of purple/blue
- Decorative blobs and abstract shapes
- Random icons used as decoration
- Excessive drop shadows
- Pills for everything
- "Dashboard" layouts made entirely of cards
- Generic Inter + Tailwind defaults without typographic hierarchy
- Centering everything
- Excessive whitespace with no information purpose
- Arbitrary animations
- Generic SaaS landing-page aesthetics

## Prefer

- Strong typographic hierarchy
- A deliberate spacing scale
- Restrained borders
- Subtle or no shadows
- Asymmetric layouts where appropriate
- Clear alignment systems
- Dense but readable information layouts
- Purposeful whitespace
- Distinctive typography
- Consistent component geometry
- Visual hierarchy based on importance, not decoration
- Real content rather than placeholder text

Before creating a component, consider whether it actually needs
a container/card. Not everything should be a card.

The result should look like a product designed by a senior product
designer, not a collection of Tailwind components.
